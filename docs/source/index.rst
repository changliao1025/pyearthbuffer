Welcome to PyEarthBuffer documentation!
=======================================

PyEarthBuffer provides geodesic buffer operations for vector geometries using
distances in meters on the WGS84 ellipsoid.

.. note::
   PyEarthBuffer is part of the **PyEarthSuite** ecosystem. It builds on
   ``pyearth`` geometry and geospatial utilities and focuses on vector buffers
   for in-memory geometries and vector files. Raster mask buffering is
   experimental and is documented separately.
